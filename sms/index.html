SMS Gateway not configured.
Add two environment variables in your Vercel project settings:

SMSGATE_USERNAME — your SMS Gate login username
SMSGATE_PASSWORD — your SMS Gate login password

Also run this SQL in Supabase to create the messages table:

CREATE TABLE sms_messages ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, phone_number text NOT NULL, message text NOT NULL, direction text CHECK (direction IN ('outbound','inbound')), status text DEFAULT 'pending', sms_gate_id text, created_at timestamptz DEFAULT now() ); CREATE INDEX ON sms_messages (phone_number, created_at);

Then set the SMS Gate webhook URL to:
https://portal.goldsure.com.au/api/battery/request-callback?action=webhook
