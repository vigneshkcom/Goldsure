Step 1: Identify the Status
"Look at all the alarms. What is the red LED doing?"
A
Slow Flash (Alarm Memory)
Red LED flashes once every 20 seconds
B
Fast Flash (Active Nuisance)
Rapid red flashing detected
Logic: This unit was the "Initiator" that triggered a recent alarm.
"This is an alarm memory indicator. To clear it, press and hold the Test/Hush button for 1-2 seconds."
Agent Note: If the memory clears and the system tests OK, the issue is resolved. If the memory won't clear or the test fails, ESCALATE TO VIGNESH.
Logic: This unit is currently detecting a nuisance (dust, steam).
"That unit has detected a nuisance. Please press the center button once to silence it and vacuum the vents."
Agent Note: If the unit persists after cleaning, ESCALATE TO VIGNESH.
