Agent Diagnostic Guide

Step 1: Identify the Triggering or Faulted Unit

"Could you please walk around and check each smoke alarm, and tell me if any unit has a fast-flashing red light right now?"
Agent Internal: Fast-flashing Red = active alarm / trigger unit
CUSTOMER RESPONSE:
A
YES - Fast-flashing red light found
Customer has identified an alarm with rapid red flashing
B
NO - No fast-flashing red light anywhere
Proceed to Step 2: Fault Check
Agent Response:
"Thank you. That is the alarm that triggered. Let's focus on that unit."
Next Steps:
  1. Check for emergency: Ask if smoke or fire is present near that unit
  2. If no emergency: Instruct to press Hush button to silence (10 minutes)
  3. Investigate cause: Check for cooking smoke, steam, dust near that unit
  4. Alarm memory: Unit will flash red every 20 seconds for 12 hours
  5. Clear memory: Press Test/Hush button to clear memory indicator
Step 2: Fault Check
"That is okay. Please look at the alarms again and tell me if any unit has a Yellow light flashing, or a Red light that flashes at the same time as a beep."
Agent Internal: Yellow flashing = sensor fault / dust / system fault
Red + beep every ~54 seconds = low battery or end-of-life
FAULT CHECK RESPONSE:
C
YES - Yellow light or Red light with beep found
Customer has identified a faulted unit
D
NO - No yellow light and no red light with beep
Proceed to Step 3: Power Check
Addressing Fault Indicators:
  1. Yellow flash (1x every 54 seconds): Low battery hush mode - Escalate
  2. Yellow flash (2x every 54 seconds): Sensor fault - Clean vents with soft brush
  3. Yellow flash (3x every 54 seconds): System fault - Escalate
  4. Red flash + beep (every 54 seconds): Low battery - Escalate
Step 3: Power Check (AC Models)
"Understood. On the front of the alarms, do you see a solid, constant Green light, or is that light completely off?"
Agent Decision Logic:
Green light ON (solid): Power is present → proceed to manual test
Green light OFF: Power is not reaching the alarm → check circuit breaker
POWER CHECK RESPONSE:
E
Green light ON (solid)
Power is present to the alarm
F
Green light OFF
No power to the alarm
Proceed to Manual Test
"Thank you. Since power is confirmed and there are no visible fault indicators, I'll guide you through a manual test."
Manual Test Procedure:
  1. Radio Link Test: Hold any alarm's test button for 1 second - all interconnected alarms should beep
  2. Individual Test: Press and hold test button on each alarm individually
  3. Check Response: Each should beep loudly and flash red rapidly during test
  4. Identify Non-Responding Unit: Any unit that doesn't respond is faulty
  5. Battery Units: Press test button - should flash green and beep
Power Issue Detected
"That usually means the power to the alarms is off. Please check your circuit breaker or fuse box and let me know once power is restored."
Customer Instructions:
  1. Check circuit breaker: Locate and check the breaker for the smoke alarm circuit
  2. Reset if tripped: Flip breaker off, then back on if found tripped
  3. Verify power: Check if green light returns on AC units
  4. If no power: May need electrician if breaker continues to trip
  5. Battery backup: AC units have battery backup - they should still function

LED Status Reference

Fast-flashing red: ACTIVE ALARM - Smoke detected
Red flash + beep (every 54 seconds): LOW BATTERY - Escalate
Red flash (every 20 seconds): ALARM MEMORY - Was triggered recently
Red flash (every 10 seconds): HUSH MODE - Alarm silenced for 10 minutes
Yellow flash (1x every 54 seconds): LOW BATTERY HUSH MODE
Yellow flash (2x every 54 seconds): SENSOR FAULT - Clean vents
Yellow flash (3x every 54 seconds): SYSTEM FAULT - Escalate
Solid green (constant): AC UNIT - Mains power connected
Green flash (test button): BATTERY UNIT - Press test to check

Diagnostic & Resolution Matrix

Scenario Diagnostic Questions Resolution Logic
False Alarm / Nuisance "Is the unit near a bathroom, kitchen, or AC vent?"
"Has it been cleaned in the last 30 days?"		 Fix: Instruct to clean perimeter vents. Use the push-to-open hinge to access.
If persists: Escalate.
Single Beep (54s) "Count the seconds between beeps. Is it exactly 54 seconds?" Fix: Low Battery. Internal 10-year lithium.
Escalate.
Double Beep (54s) "Is it two short beeps together every 54 seconds?" Fix: Sensor Fault. Clean vents thoroughly.
If continues >1 hour: Escalate.
No Power / Dead "Is the small green light glowing on the face?" Fix: AC Power Loss. Check breaker.
If power on but unit dead: Escalate.
