Agent Diagnostic Guide V2.7
Step 1: Identify Triggering Unit
"Could you walk around and check the alarms? Does any unit have a fast-flashing red light right now?"
A
YES - Fast-flashing red found
Rapid red flashing detected
B
NO - No fast-flashing red
No rapid flashing detected on any unit
Logic: This unit is the "Initiator" detecting a nuisance.
"That unit has detected a nuisance like dust or steam. Please press the center button once to silence it. Then, use a vacuum or soft brush to clean the perimeter vents."
Agent Note: If the unit persists after cleaning, ESCALATE. Otherwise, proceed to Full System Test to ensure connectivity.
Step 2: Fault Check
"Is any unit flashing Yellow, or is there a Red light flashing at the same time as a beep?"
C
YES - Fault Found
Yellow or Red+Beep detected
D
NO - No Fault Indicators
No fault lights or beeping patterns
FAULT DETECTED: Refer to LED Status Reference below for exact pattern.
Yellow flash (2x every 54s): Sensor fault - Clean vents
Yellow flash (1x every 54s): Low battery hush mode - ESCALATE
Red flash + beep (every 54s): Low battery - ESCALATE
Yellow flash (3x every 54s): System fault - ESCALATE
Step 3: Model Identification & Power Check
"This is likely a nuisance alarm. Please clean the vents. Now, looking at the alarm, is there a solid green light glowing on the face?"
E
Green light ON (Solid)
AC/Hardwired Model - Power confirmed
F
Green light OFF
10-Year Battery Model - No constant light
AC Power confirmed. If green light was OFF, check circuit breaker.
Battery unit identified. Tap test button to confirm green flash (Power OK).
Full System Test (Radio Link Test)
"Press and hold the button for 1 second. This tests the whole network."
1. One unit is held for 1s.
2. After a delay, ALL other units flash Green and beep 6 times.
3. If an alarm does not sound: It must be re-paired.
4. Interference: Steel reinforcement or concrete can block signals.
Case De-escalation
"It looks like the system is powered and communicating correctly now. Cleaning the unit should prevent those nuisance alarms.

If the alarm sounds again without a reason, please call us back immediately so we can look at replacing the unit."
Internal: Log as 'Nuisance Alarm - Cleaned & Tested'.
